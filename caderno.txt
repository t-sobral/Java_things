Streams:

	- The stream api is used to process collections of objects.

	- The difference between a collection and a stream is the fact the streams dont sotre data, they just 
	proccess it in some way, one operation on a stream produces a result but doenst change the source 

	- We can also say that the list "Exists" and the stream "doesnt".

	- The filter() method is specially usefull when we want the data to match a certain condition.
	
	- The map() method allows us to transform each element, for example map (String :: toUpperCase), it 
	changes every data to upper case.

	- The sorted() method allows to sort the content of the list.

	- The collect() method allows us to convert back the stream to a collection, for example .toList() turns 	the stream to a list.

	- The count() method allows us to literally count xD.

	EX:
	
	Optional<Integer> result = numbers.stream().filter(n -> n>10).findFirst();
	result.ifPresent(System.out :: println) (method reference of a particular method of a particular object).	
	-We are using the findFirst ot find the first number that satisfies the condition, and then printing it
	by using a method refernce (Obj :: method).
